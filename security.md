# 🔐 Zero-Trust Security

## 4-Layer Model
1. Defense in Depth
2. No Secrets to Agents
3. Stage & Vet Writes
4. Log Everything

## Threat Model (STRIDE)
- Spoofing: 2FA
- Tampering: SHA-256 logs
- Repudiation: audit trail
- Info disclosure: secrets scan
- DoS: rate limit
- Elevation: least privilege
